# Roadmap

## Phase 1 (implemented)

- Optional manifest mode (`-ManifestFile`)
- Task listing (`-ListTasks`)
- Optional direct task selection (`-TaskName`)
- Manifest task -> image resolution with optional image index
- Backward-compatible ad-hoc discovery mode retained

## Phase 2 (next)

- Add optional per-task driver injection
- Add optional per-task unattend copy behavior
- Add validation messages for reserved manifest keys

## Phase 3

- Add optional BIOS/MBR layout branch and task-level layout policy
- Add stronger disk-policy controls for unattended execution
- Add structured logs for auditability

## Phase 4

- Add optional image capture workflow
- Add deployment report output (JSON + console summary)
